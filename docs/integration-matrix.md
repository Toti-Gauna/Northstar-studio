# Integration matrix

| Function | Implementado local | Simulado externo | Conectado comprobado | Pendiente por acceso/revisión |
|---|---|---|---|---|
| API, DB, sessions, roles, quotas | Express + dedicated PostgreSQL + opaque cookies | None | Local Docker PostgreSQL verified | Production identities/topology |
| Conditional brief, estimate, packages | Deterministic rules/catalog/integer server pricing | No AI claim | Local API verified | None for demo |
| Quote draft/send/version diff | Immutable snapshots, server calculation | None | Local DB workflow verified | None for demo |
| Acceptance and handoff | Exact confirmation, atomic project/milestones/tasks | No payment/signing simulation | Concurrency verified locally | Real contracts/signature/payment only if separately scoped |
| PDF | Server snapshot file/hash, protected download | None | PDF bytes/text/download verified | Hosted durable disk selection |
| Attachments | Private validated files + ownership checks | None | Local storage tested | Production storage/antivirus/retention review |
| Notifications/reminders | Durable inbox/outbox + DB reconciliation/dedupe | Represents a sales notification locally | Local effects verified | External email/WhatsApp not connected and not sent |
| CMS/settings | Draft/published/history, profile-specific catalogs | Synthetic company/content | No-rebuild local export verified | Brand/contact/content approval |
| Analytics | Workspace audit events, synthetic seeds labeled | No real revenue/ROI | Counts verified | Commercial outcomes not claimed |
| Static frontend hosting | Next export and CSP configuration prepared | None | Real local export served/tested | Hostinger/Pages URL/origin not provisioned |
| Node hosting | Render blueprint prepared | None | Local compiled runtime verified | Render service/domain/disk/billing not provisioned |
| Managed database | Config/migration for independent PostgreSQL | None | Local PostgreSQL real | Neon access and project not created |
| Calendar, payments, LLM, CRM sync | Not required for this demo | None | None | Not part of authorized scope |

Notion sources and official library documentation were read where available; these are construction references, not runtime product integrations. Local notifications are real inside the workspace; the external communication effect is absent, not reported as delivered. The demo does not need paid tools, provider keys or newly created accounts to run.
