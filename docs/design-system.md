# Design system

Editorial, warm and technical. Original SVG compositions and a working proposal preview establish the identity; no purchased imagery, client logos, testimonials, invented awards or results. Case artwork is generated by the application's SVG code and labeled demonstration.

## Tokens

Paper `#F6F1E8`; surface `#FFFCF7`; navy `#14263D`; secondary `#596575`. Decorative copper `#BC7956`; interactive/text accent `#965538`. Success `#286247`, error `#A23132`, warning `#805415` plus icon/text. Separator `#DED7CC`. Controls/panels 8–12px radius; dialogs 16px. Spacing follows 8/12/16/24/32/48/64/96. 1280px content, 7/5 hero proportions, editorial rows rather than repetitive dashboard cards.

Instrument Serif headlines; Inter UI with system fallbacks. Web assets are bundled/self-hosted by Fontsource. PDF headline TTF and its SIL OFL license are in `assets/fonts`; PDF UI uses standard Helvetica. Fontsource license files are retained with installed packages; upstream font licenses and attribution are copied to the assets directory. No runtime third-party font request is needed. Fluid headlines use clamp, UI figures stay sans-serif.

Brand controls retain light paper/dark ink and accessible accent contrasts. Server validates navy/accent against both configurable paper and fixed surface, and paper against fixed secondary text. This is a deliberate light editorial theme, not an untested arbitrary dark-mode generator.

## Surfaces and primitives

Public web: compact promise, interactive live estimate, service rows, two synthetic cases, process SVG and final CTA. Deep content lives on separate exported routes. Operator: sidebar/nav, scoped workspace label, true filters/pagination, contextual request detail, activity rail and dense editing. Client: navy proposal cover, history, exact option, scope sections, document/acceptance actions and milestones.

Shared buttons/fields/status/tables/empty/loading/error states, modal/confirm, toast, tabs, accessible details and download actions. Native dialog supplies modal focus/escape; cleanup restores prior focus. Explicit irreversible-in-demo actions (send/freeze, accept, decline, archive/publish/reset) show concrete confirmation. Backend results precede success feedback/navigation.

## Motion scenes

1. Hero: GSAP scoped stagger 80ms, approximately 720ms; initial rendered content remains readable.
2. Process: original SVG trace through brief/scope/quote/project, natural ScrollTrigger scrub, no pin/scroll hijack. Mobile uses a clear vertical node stack.
3. Live preview: line/amount transform transition after a valid API estimate; previous total is not presented as a newly confirmed result.
4. Brief: forward/back 200ms transform, focused heading or first invalid field, announced step.
5. Compare: real changed rows with text/icon/highlight, including price/quantity/scope/day changes.
6. Acceptance: only after transactional server result, toast and subtle 220ms project arrival; no optimistic acceptance/confetti.
7. Cases: one-time 300ms transform reveal. Text opacity stays 1 to maintain contrast throughout scrolling.
8. Buttons/tabs/toasts/dialog states: 150–250ms, tables are not globally animated on filters.
9. Tour: six 15-second guide steps, pauses on pointer/keyboard interaction, no automatic business commands.

GSAP base, ScrollTrigger and React hook are explicitly imported. matchMedia scopes and reverts on cleanup; no background loops in operational views. Reduced motion removes transforms/scrub and CSS animations; semantic feedback remains. Layout is reserved around session/data loading to reduce shifts.

## Accessibility/responsive

Keyboard-visible focus, skip link, named controls, linked errors/hints, actual disabled states and live messages. Table overflow stays within named focusable regions; portal navigation scrolls within its own container. Role/language selects work on mobile, and dialogs close with Escape and restore focus. Tested widths and automated axe outcomes are in QA; they are not a certification.

Public content base 14px, descriptions 12–16px, compact operational table/form text 11–12px and small editorial references 9–10px. Main controls target ~44px; visible labels remain separate from technical advanced JSON configuration. Synthetic uploads and local notification mode are labeled where used.
