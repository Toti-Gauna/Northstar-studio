# 90-second sales demonstration

Use synthetic data only. Start one browser workspace; keep its ID/reference visible. A second browser window with separate cookies demonstrates isolation if asked. The tour button guides six 15-second scenes and pauses on interaction; it never submits or accepts automatically.

| Time | Action | Factual narration |
|---|---|---|
| 0–15 s | Home: change package/scope in Live Preview; open brief | “This is a working starting estimate from a configurable service catalog, not a final contractual quote.” |
| 15–30 s | Complete synthetic brief, add synthetic reference, send and note request ID | “The server records this exact brief. The reference continues through the workflow.” |
| 30–45 s | Switch to operator; qualify, draft and send V1 | “The operator sees the same request, defines scope and freezes a proposal. Notification is local; no external email is sent.” |
| 45–60 s | Switch to client, comment; operator creates/edits/sends V2 | “A sent version is not overwritten. Changes create a revision.” |
| 60–75 s | Client compares V1/V2, chooses one option, reviews checkpoints and accepts | “The amount/scope differences are real. Acceptance records exactly this option and version; it is not certified signing or payment.” |
| 75–90 s | Open actual project/milestones, download snapshot PDF, reload | “The transaction creates the work plan once. Refresh preserves the data. Other visitors have isolated workspaces.” |

For a fast live presentation, prepare a synthetic brief/V1 in the same workspace ahead of time, then create/send V2 during the demonstration. Do not pretend prepared rows were typed live. A fresh fully typed end-to-end explanation may take longer than 90 seconds.

## Channel framing

- Published lead: show how an incoming request becomes a budgetable, traceable scope. Ask about actual services/questions/review process; do not claim the demo closes sales.
- Cold email: demonstrate the specific form/quoting/follow-up problem with a factual screenshot or demo-card file. No email is sent by this product or this construction task.
- Referral/in-person: choose Architecture or Technical Services as appropriate, discuss required site/equipment information and what the client must provide. Keep company/cases labeled fictional.
